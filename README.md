# Python OOP Practice Tasks

Small exercises from a Python backend course, focused on classes, inheritance, constructors, and calling parent methods with \x60super()\x60.

## Exercises in \x60oop-task.py\x60

1. **Devices** — a shared \x60Texnika\x60 parent class with notebook, television, and smartphone subclasses.
2. **Transport** — a \x60Transport\x60 parent class with electric car, supercar, and truck subclasses.
3. **University** — university staff and student roles, followed by computer and furniture inventory objects.

The examples are written in Uzbek and use only the Python standard library.

## Run

\x60\x60\x60bash
python oop-task.py
\x60\x60\x60

The file currently defines the classes. To explore them, create an instance in a Python shell or add a small example under a \x60__main__\x60 block.

## Learning goals

- Reuse common fields through inheritance
- Initialize parent classes with \x60super().__init__(...)\x60
- Add fields and display methods in subclasses
- Model related objects with simple class hierarchies

This is a learning exercise rather than a production-ready inventory system.
